A one-line review of the most boring everyday object: a rubber band.

The program writes a single funny, true review line to `/output/entry.txt` — a rubber band that held cables together for three years, then retired by snapping in its owner's face on the one morning it was actually needed. That is exactly how rubber bands behave: they dry out, go brittle, and snap without warning.
